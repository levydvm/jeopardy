    How to play and edit
    1. Edit the board. Choose Edit game, rename the categories, and set the points at the start of each row. Click a square to write a question and an answer. Add or remove categories and point rows. Removing one deletes its questions and asks you to confirm.
    2. Name the teams before you play. You can add or remove teams in the editor. Removing a team deletes its score and asks you to confirm.
    3. Play. A team picks a category and a point value. Click the square to show the question, then click again (or press Enter) to show the answer. There is no automatic judging.
    4. Score by hand. While a question is open, + and − add or subtract that question’s points for one team. Scores may go below zero. Back to grid marks the square played, and it turns grey.
    5. Adjust on the grid. Set Adjust by, then use a team’s + or − to add or subtract that amount — a bonus, a correction, or a penalty you choose.
    6. Present fills the window for a projector or TV. Team scores stay on screen when a question is open. Fullscreen hides the browser toolbar. Exit presentation (or Escape, when no question is open) returns to the page.
    7. Restart game clears played squares and sets scores to zero. Questions, categories, point values, and team names stay. New blank game and Load example replace the current game. Each asks you to confirm.
    8. Keep a copy. Export JSON downloads the game, and Import JSON loads one back. With a Google Client ID in js/config.js, Sign in with Google can save and open games in a Drive folder named Jeopardy Games.

    Only squares with both a question and an answer can be played. The line under the board shows how many are ready, or how many are left.
